# Mission Control Edge v0.1.1

This maintenance release refreshes the pinned CI actions and TypeScript test
dependencies and publishes the provider SDK as version 0.1.1. The provider
protocol, public interfaces, supported platforms, and Apache-2.0 license remain
the same as v0.1.0.

The release includes Linux and macOS CLI archives for amd64 and arm64, a source
archive, checksums, SPDX SBOMs, repository-bound attestations, and the public
`@gocodealone/mission-control-provider-sdk` package.

## Candidate gates

Tag only the reviewed public merge commit after all Go, TypeScript, generated
document, security, license, cross-language conformance, release snapshot, and
`ci/clean-consumer` checks succeed on that exact commit. The main-only clean
consumer job resolves that public Go commit without workspace replacements and
packs the candidate SDK into a fresh consumer environment. A skipped consumer
check on a pull request does not satisfy the release gate.

## Published consumer verification

The tag-only release workflow verifies a fresh Go consumer against `v0.1.1` and
a fresh TypeScript consumer against the published SDK 0.1.1 after both publishing
jobs succeed. It verifies the npm tarball's provenance and SPDX attestations
against the release workflow and exact tag before running conformance. Release
completion requires this consumer job to succeed as well as both publishing
jobs.

No pull-request workflow publishes a release or package. The consumer job has
only read permissions for repository contents, package downloads, and
attestations. Go and npm caches are isolated by the existing consumer script.

Observed digests remain in the release assets, package version, SBOMs, and
attestations. If this version is defective, revert the relevant change on main
and publish a new patch version; never replace immutable tags or artifacts.
